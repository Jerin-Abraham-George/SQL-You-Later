# 🛒 E-commerce Analytics SQL Project

## 📘 Overview

The **E-commerce Analytics SQL Project** is a business-focused SQL analysis project centered on understanding e-commerce performance, customer behavior, website effectiveness, marketing channel efficiency, and product sales trends.

Using **Microsoft SQL Server**, this project transforms raw business data into actionable insights by analyzing website traffic, conversion funnels, revenue trends, product performance, and customer purchasing behavior.

---

## 🎯 Objectives

- Analyze website traffic and marketing channel performance.
- Evaluate landing page effectiveness and conversion rates.
- Measure business growth through sessions, orders, and revenue trends.
- Identify top-performing products and assess profitability.
- Examine customer purchasing behavior and cross-selling opportunities.
- Support data-driven business decisions using SQL analysis.

---

## 🧰 Tools & Technologies

- **Microsoft SQL Server** – Database querying and analytics.
- **SQL** – Data extraction, transformation, aggregation, and reporting.
- **SQL Server Management Studio (SSMS)** – Query development and execution.

---

## 🗂️ Project Structure

### 📈 Traffic Source Analysis

- Marketing channel traffic trends.
- Gsearch brand vs. non-brand campaign performance.
- Device-level traffic analysis.
- Channel conversion performance.

### 🌐 Website Performance Analysis

- Landing page conversion analysis.
- Website pageview trends.
- Landing page A/B testing evaluation.
- Conversion funnel analysis.

### 📅 Business Trends & Seasonality

- Monthly and quarterly growth trends.
- Session-to-order conversion rates.
- Revenue per order and revenue per session.
- Business seasonality patterns.

### 🛍️ Product Analysis

- Product revenue and margin analysis.
- Sales performance by product.
- Impact of new product launches.
- Cross-selling behavior and opportunities.

### 👥 User Analysis

- Customer purchasing behavior.
- Repeat purchase patterns.
- Customer activity and order trends.
